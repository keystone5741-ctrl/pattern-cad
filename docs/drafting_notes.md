# 제도 규칙 메모

원형을 규칙으로 옮기면서 확인한 내용. 도면(포트폴리오)은 전체적으로 조금씩 부정확할 수 있으므로,
애매한 부분은 매번 물어보고 여기에 답을 기록한다.

## 시추니 기본 원형

| 항목 | 규칙 | 출처 |
|---|---|---|
| 앞어깨끝점 | 옆목점에서 **가이드점(앞중심에서 7.1/2” 옆, 기준선에서 2” 아래)을 향한 각도**로, 길이는 **뒤어깨길이 − 1/4”(견갑골 이세분)** | 확인됨 |
| 견갑점(뒤어깨다트 끝) | 다트 위치에서 **어깨선에 직각으로** 4” | 확인됨 |
| 암홀이 품선에 닿는 높이 | 어깨끝 ~ 가슴선 사이. **뒤는 중간(1/2), 앞은 2/3 지점 정도.** 원하는 암홀 형태에 따라 달라짐 → 치수 `앞암홀접점비율`, `뒤암홀접점비율` | 확인됨. 단, 도면 실측은 앞도 약 1/2 — 재확인 필요 |
| 유장 | **타겟 연령대에 따라 달라짐.** 나이가 들수록 가슴이 커지고 처져 유장이 길어지고, 등길이·가슴둘레도 커짐. 사이즈코리아(연도별·나이대별 측정) 참고 | 확인됨 |
| 등길이 | 일반적으로 고정 | 확인됨 |
| 앞품·뒤품 | 가슴둘레를 따라가거나, 브랜드가 원하는 암홀 곡선 형태에 따라 달라짐 | 확인됨. 공식은 나중에 |
| 진동깊이 | 아이템이나 가슴둘레에 따라 달라짐 | 확인됨. 공식은 나중에 |

## 미확인

- 도면 앞판 위 `7.1/2”` 표기 — 앞어깨 가이드점의 가로 위치로 해석 (위 규칙과 일치)
- 도면의 BP 는 옆목점에서 9.87” 위치. 규칙(유장 10”)과 0.13” 차이 — 도면 오차로 봄

## 사이즈·핏 (계획 확정)

- 사이즈 표기 체계는 여러 개(55/66, S/M/L/XL, 130 등) 중 선택, 기준 사이즈도 선택
- 핏 4단계 (타이트 / 레귤러 / 루즈 / 오버). 원형 생성 후 손으로 수정 가능
- 개발 순서: 상의 → 스커트 → 팬츠 → 아우터
