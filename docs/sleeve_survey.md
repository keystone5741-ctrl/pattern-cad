# 소매 조사 — 암홀과 소매의 관계

포트폴리오 상의·원피스 아이템의 소매 제도 규칙을 도면 주석과 유의사항에서 모은 것.
(자켓은 두 장 소매라 별도 — 아우터 단계에서)

## 공통 구조

모든 한 장 소매가 같은 틀로 제도된다.

- **소매산높이 = AH/3 + 조정값** (AH = 앞AH + 뒤AH, 몸판 암홀 곡선 길이)
- 소매산점에서 소매통선까지 **사선 길이 = 앞AH + 이세, 뒤AH + 이세** → 소매통 폭은 결과값
- 소매산 곡선: 위쪽은 사선 밖으로(약 0.6”), 아래쪽은 안으로(0.2~0.5”). 소매산점 옆 2.1/4”(뒤)·2”(앞)에서 소매통 끝 안쪽 1”(뒤)·1.1/2”(앞)로 그은 가이드선과 사선의 교점을 지난다
- 팔꿈치길이 12”, 밑단 양 끝 옆선 3/8” 올림

## 읽히는 관계

1. **소매산 조정값과 사선 이세가 같이 움직인다.** 조정값이 음수(낮은 소매산)면 이세도 음수(소매가 암홀보다 짧아 늘려 봉제 — 다이마루), 양수면 이세도 양수(오그려 봉제 — 우븐·드레시). 대략 이세 ≈ 조정값의 1/2~2/3.
   → 자동 생성에서는 "소매산 단계" 하나로 두 값을 같이 정할 수 있다.
2. 소매산이 높을수록 소매가 일자로 떨어지고(자켓·드레시), 낮을수록 A자로 떨어지며 활동성이 좋다(티셔츠·아노락). 낮은 소매산은 "소매에 비리가 가는" 단점 (p.50).
3. 오버사이즈는 소매산을 낮춘다 (오버 블라우스 −7/8”, 후드 이세 −5/16”). 어깨가 15”를 넘으면 어깨선을 1/4”~3/16” 내려 암홀이 흐르는 것을 막는다 (p.50).
4. 앞·뒤 이세가 같은 아이템이 대부분이지만, 뒤소매 여유는 소매통선에서 들어가는 분량으로 조절한다 — 많이 들어갈수록 실루엣이 예쁘고 불편, 적을수록 편하고 분량이 흐름 (p.50). 앞품 쪽은 활동분량이 필요 없어 여유를 없애는 편이 좋다.
5. 앞소매선은 몸판에서 찾은 실제 상동선과 소매중심선에서 3/4~1” 내려온 선을 포개어 **앞암홀선을 그대로** 그린다 (p.50) → 앞소매산 곡선 아래쪽은 몸판 앞암홀과 같은 모양.

## 소매산 단계 (묶음)

위 표를 한 선택값으로 묶었다. 단계를 고르면 조정값과 이세 기본값이 같이 정해진다.
**이세는 아이템·원하는 소매 각도·원단이 이세를 먹는지·공장이 이세 처리가 가능한지에 따라 매번 바뀌므로**, 스타일에서 따로 덮어쓴다.

| 단계 | 소매산 조정 | 이세 기본값 | 예 |
|---|---|---|---|
| 낮음 | −1.5/8” | −1/2” | 스웻 (다이마루·캐주얼) |
| 약간낮음 | −3/4” | −3/8” | 오버사이즈 블라우스, 타이트 티, 점프수트 |
| 기본 | −1/2” | −3/8” | 셔츠 칼라 블라우스 |
| 중간 | −1/8” | −1/8” | H라인 원피스 |
| 약간높음 | +1/2” | +1/2” | 플랫 칼라, 푸시 보우 |
| 높음 | +1.5/8” | +1” | 머메이드, 차이나 칼라 (드레시) |

## 규칙 파일

`blocks/sleeve_basic.yaml` — 입력: 앞AH, 뒤AH, 소매산조정, 앞·뒤소매이세, 소매길이, 팔꿈치길이, 가이드 4개, 소매부리들임, 옆선올림.
아이템별로는 조정값·이세만 바꾸면 된다. 몸판 원형과 자동 연결(앞AH·뒤AH를 몸판 암홀 곡선 길이에서 계산)은 스타일 단계에서.
